# NOTES & BEST PRACTICES
# ==============================================================================

# Testing:
# 1. Google Search Console > robots.txt Tester
# 2. https://www.google.com/webmasters/tools/robots-testing-tool
# 3. https://en.ryte.com/free-tools/robots-txt/
# 4. Test URL: https://your-domain.com/robots.txt

# Important Notes:
# - Robots.txt is a public file - don't use it for security
# - Use authentication/authorization for actual security
# - Disallow doesn't mean search engines will remove pages from index
# - Use meta robots tags or X-Robots-Tag headers for better control
# - Googlebot may ignore crawl-delay (use Search Console instead)
# - Changes may take days/weeks to take effect

# Common Mistakes to Avoid:
# ✗ Don't disallow CSS/JS files (breaks rendering in search results)
# ✗ Don't block entire site unless intentional (e.g., staging site)
# ✗ Don't use robots.txt for sensitive data (it's publicly accessible)
# ✗ Don't forget trailing slashes (they matter!)
# ✗ Don't block /api/ if you have public API documentation

# Performance Tips:
# ✓ Keep file size under 500 KB (limit for most crawlers)
# ✓ Use specific rules instead of wildcards when possible
# ✓ Test regularly with Search Console
# ✓ Monitor crawl stats in Search Console
# ✓ Update sitemaps when site structure changes

# Security Considerations:
# - This file doesn't provide security (it's just guidance)
# - Use proper authentication for sensitive areas
# - Consider rate limiting at server/CDN level
# - Monitor for unusual bot traffic
# - Block malicious IPs at firewall level

# SEO Impact:
# ✓ Prevents duplicate content issues
# ✓ Saves crawl budget for important pages
# ✓ Helps search engines understand site structure
# ✓ Improves indexing efficiency
# ✓ Reduces server load from bot traffic
# ✓ Protects user privacy (kids, parents, attendance data)

# Maintenance:
# - Review quarterly
# - Update when adding new protected sections
# - Monitor Search Console for crawl errors
# - Test after any changes
# - Keep track of blocked vs indexed pages
# - Audit for any accidental exposure of sensitive routes
